auth

Вход, сессия, регистрация

POST /api/auth/login

Вход

LDAP (если включён), иначе локальная база. Устанавливает cookie guard_session.

Доступ: без авторизации

Коды ответов

  • 200 — Успех
  • 400 —
  • 500 —

Пример запроса

curl -X POST "https://antiplagiat.example/api/auth/login" \
  -H "Content-Type: application/json" \
  -d'{
  "username": "admin",
  "password": "secret"
}'

Пример ответа 200

{
  "success": true,
  "user": {
    "username": "admin",
    "role": "admin",
    "fullName": "Администратор",
    "institution": "БГУИР",
    "institutionId": "bsuir"
  }
}

Пример ошибки 400

{
  "success": false,
  "error": "Некорректный запрос"
}

documents

Загрузка, список, статусы, файлы

POST /api/upload

Загрузка файла и постановка в очередь анализа

Возвращает 202 сразу. ML выполняет analysis-worker.
Плагин Moodle передаёт X-API-Key и username (LDAP uid).

Доступ: сессия admin/пользователя (cookie guard_session) или заголовок X-API-Key или Authorization: Bearer

Коды ответов

  • 202 — Поставлено в очередь
  • 400 —
  • 409 — У пользователя уже есть активная задача
  • 503 —

Пример запроса

curl -X POST "https://antiplagiat.example/api/upload" \
  -H "Cookie: guard_session=…" \
  -H "X-API-Key: <MOODLE_API_KEY>" \
  -H "X-Moodle-Username: 7123456" \
  -F "file=@lab.docx" -F "title=Лабораторная" -F "content=текст работы не короче 50 символов" -F "category=lab" -F "username=7123456"

Пример ответа 202

{
  "success": true,
  "status": "processing",
  "jobId": 3,
  "document": {
    "id": 42,
    "title": "Лабораторная",
    "category": "lab",
    "status": "processing",
    "localPlagiarismPercent": 12.5
  }
}

Пример ошибки 401

{
  "success": false,
  "error": "Требуется вход"
}
